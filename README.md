# PJBL-2 LogicForge — Sesi 2

## Stack
- Python
- Flask
- SQLite
- HTML/CSS/JavaScript
- Matplotlib
- matplotlib-venn

## Menjalankan
1. Pastikan Python sudah terpasang.
2. Buka terminal pada folder proyek.
3. Install dependency:
   `pip install -r requirements.txt`
4. Jalankan:
   `python app.py`
5. Buka alamat yang muncul, biasanya `http://127.0.0.1:5000`.

## Fitur
- Input dan tampil data mahasiswa
- Import CSV
- Dataset contoh 1 dan 2
- Kategori A, B, C, D sesuai PJBL-2 Sesi 1
- Union
- Intersection
- Difference
- Complement
- Diagram Venn otomatis untuk dua himpunan
- Prinsip Inklusi-Eksklusi untuk 2 atau 3 himpunan
- Hapus data

## Kategori
A = Mahasiswa Informatika
B = Mahasiswa Semester 3
C = Mahasiswa Laki-laki
D = Mahasiswa Aktif
